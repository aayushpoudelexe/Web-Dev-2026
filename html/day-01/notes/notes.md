HTML

HTML stands for Hyper Text Markup Language.
It is the standard language used to describe the structure and meaning of content on webpages.

HTML is a markup language, not a programming language.
It labels and organizes content rather than performing calculations or making decisions by itself.
It uses elements - that tell a browser what each piece of content represents.
The browser reads those elements and displays the webpage

Web browsers read HTML and use it to build the web page they display.

Think of a web page like a house
HTML is the structure: walls, rooms, doors.
CSS is the appearance: colors, sizes, decoration.
JavaScript is the behavior: opening doors, responding to buttons, interactions.
